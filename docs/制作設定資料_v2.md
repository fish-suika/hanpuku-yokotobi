# 分身反復横とび v2（大会と強化） — 制作設定資料（2026-11-25）

v1（2026-11-07 完成・公開）の設定資料は `制作設定資料.md`。この資料は、v1 の遊び（右左左右・勢いと分身・記録係が全員数える）をそのまま核にして、**くり返し遊ぶ理由**を足すための追加分だけを書く。v1 に書いてあることは繰り返さない。

## 決定事項

**本人が決めたこと**
- 目的：**CrazyGames に出せるくらい作り込む**（2026-11-25）。CrazyGames では、数分で遊び終わる小さなゲーム2本が「全体の品質が基準に届かない」で不採用になった（2026-11-20・21）
- 土台は **分身反復横とび**。YouTube Shorts の反応がほかの作品より大きかった（48時間後 9,509 回・視聴を継続 62.5%・高評価 19。2位は BULLET TIME の 2,122 回）
- 方向は **大会と強化で深くする**（種目を増やす案は採らない）（2026-11-25）

**Claude 案（異論がなければこのまま）**
- **v1 と同じリポジトリで v2 として作り、GitHub Pages の公開版も v2 に置き換える**。ポータル向けは英語つき・外部リンクなしの版を `sh build.sh portal` で別に出す（ほかの3本と同じ方法）
- 1回の測定は v1 と同じ **20 秒**。操作・順番・勢いと分身の仕組みも v1 のまま
- 大会を **9つ** 勝ち上がると終わり。初めての人で **20〜30分** を目安にする
- 記録が「引換券」になり、**購買部**で強化を買う。題材の「学校の体力測定」から言葉と見た目をそろえる
- 進み具合はブラウザに保存する（localStorage）。CrazyGames の保存の仕組み（SDK）は、本公開に招待されてから
- **パソコンの横画面でも体育館を横に広げて見せる**（CrazyGames はパソコンで遊ぶ人が多いと言われるため。v1 の「次にやるなら」の候補）
- 操作説明・キー設定は v1 と同じく入れない。購買部の品物の説明だけは短い一文で出す（何が強くなるか分からないと買えないため）

## 0. 面白さの分析（追加分）

**v1 で足りなかったもの**
- 20 秒で終わり、もう一回遊ぶ理由が「ベストの更新」だけ。数回で満足して終わる
- 最上段（48人・毎秒 8 回）に、本人が PC でも届かなかった。一番の見せ場を多くの人が見られない

**考察**
- 分身の人数・記録の桁が増えていくのは、それ自体が気持ちいい（v1 の核）。これを **1回の中だけでなく、遊ぶたびに大きくなる** ようにすると、続ける理由になる
- 強化で「腕前」ではなく「届く場所」を広げる。上手な人は早く進み、苦手な人も買い物を重ねれば最上段まで届く → 見せ場を全員が見られる
- 大会が上がるたびに、**会場と記録係の大げささ** もエスカレートさせる（v1 の「周りが反応する」を、大会単位にも広げる）。体育館 → 市民体育館 → 全国 → 世界 → 宇宙
- ライバルの記録を毎回はっきり見せ、「あと少しで勝てた」で、もう一回押させる

**再構築**
- 1回の流れ：大会を選ぶ → ライバルの記録を見る → 20 秒跳ぶ → 記録用紙（ライバルとの比較・引換券） → 勝てば次の大会が開く → 購買部で強化 → また跳ぶ

## 1. ゲーム概要（v2）

- タイトル：分身反復横とび（変えない）
- コンセプト：**反復横とびを速くしすぎて分身し、宇宙大会まで勝ち上がる**
- 目指す楽しさ：v1 の楽しさ＋分身と記録がどこまでも膨らむ／買い物で強くなる手応え／大会ごとに大げさになる会場で笑う

## 2. ゲーム内容（追加分）

### 大会（9つ）

| # | 大会 | 勝つ条件（ライバルの記録の目安） | 会場と記録係 |
|---|---|---|---|
| 1 | クラスの体力測定 | 80 | 学校の体育館・担任の先生 |
| 2 | 学年の体力測定 | 200 | 同じ体育館・学年の先生たち |
| 3 | 校内大会 | 600 | 体育館・全校生徒が見ている |
| 4 | 市大会 | 2,000 | 市民体育館・審判 |
| 5 | 県大会 | 6,000 | 大きなアリーナ・審判団 |
| 6 | 全国大会 | 2万 | 全国大会の会場・テレビ中継 |
| 7 | 世界大会 | 10万 | スタジアム・国際審判 |
| 8 | 月面大会 | 50万 | 月面・宇宙飛行士 |
| 9 | 宇宙大会 | 300万 | 宇宙空間・宇宙人の記録係 |

- 数字は仮。実装でボットを使って、進むペースが目安（全体で 20〜30 分）に合うように調整する
- 各大会にライバルを1人置く（名前と一言だけ。絵は記録係と同じくらいの小ささ）。測定中、画面の端にライバルの記録の線を出し、超えた瞬間に効果音
- 負けても引換券はもらえる（強くなって再挑戦できる）。勝った大会にはいつでも戻れる
- 宇宙大会に勝つとエンディング（記録用紙が宇宙規模になる）。その後は全大会で自己ベストを狙える

### 引換券と購買部

- 1回ごとに **記録の一部が引換券** になる（勝つと多め）。記録がそのまま通貨になるので、分身するほど早く強くなる
- 購買部の品物（それぞれ数段階まで買える。値段は段階ごとに上がる）：

| 品物 | 効果 | ねらい |
|---|---|---|
| 体育館シューズ | 勢いが落ちにくい（勢いを数える時間が長くなる） | リズムが少し乱れても保てる |
| 新しい体操着 | 段階が上がる速さの下限が下がる | 最上段に届かない問題を解決 |
| 受け身の練習 | 転んだときに勢いが下がる量が減る・動けない時間が短くなる | ミスに優しく |
| 記録係を増やす | 記録の倍率が上がる | 記録と引換券の伸び |
| 応援団 | 勢いの段階が1つ上から始まる | 出だしが速い |
| 分身の秘伝書 | **段階の上限が増える**（段階 7＝100人、8＝500人、9＝3,000人 …） | 分身と数字のエスカレート。大会の進み具合に合わせて解放 |

- 秘伝書は大会を勝ち進まないと買えない（大きすぎる数字を早く見せない）

### 画面の流れ

タイトル → 大会の一覧（勝った大会・次の大会・まだの大会） → 測定前（ライバルの紹介） → 測定（v1 と同じ） → 記録用紙（ライバルとの比較・勝敗・引換券） → 大会の一覧 or 購買部

## 3. 制作方針（追加分）

- 技術は v1 と同じ（Canvas 2D・ライブラリなし・`src/` を `sh build.sh` で1枚の HTML に）
- 見た目：会場ごとに背景・観客・記録係の絵を変える。全部描き直さず、v1 の体育館の描き方を色・大きさ・小物で作り分ける。月面と宇宙だけは背景を大きく変える
- **横画面**：今の「9:16 の遊ぶ場所を中央に置く」をやめ、横長のときは体育館を横に広げ、分身も横に並べる
- 大きな数字の表示：日本語は「万・億・兆」、英語は K / M / B
- 言葉：日本語と英語を端末の言語で切り替える（ほかの3本と同じ）
- 優先順位：大会と強化のくり返しが遊べる → 進むペースの調整 → 会場の見た目・エンディング → 横画面・英語・仕上げ

## 4. 技術的な実現方法（Claude）

- 強化は `CFG` の値（`winEnd`・`levelRate`・`stunDrop`・`stunSecs`・倍率・開始段階・`bodies`）に掛け算・足し算するだけにして、`20-logic.js` の判定の仕組みは変えない
- 保存：`hanpuku-yokotobi-save`（大会の進み具合・引換券・強化の段階・大会ごとのベスト）。v1 の `hanpuku-yokotobi-best` があれば読み込んで引き継ぐ
- 進むペースの確認：`verify.html` に「毎秒 4 / 6 / 8 回のボットが、毎回いちばん安い強化を買いながら進むと、宇宙大会まで何回かかるか」を出す
- 分身が数百人以上のときは全員を描かない（奥の列は塊の絵にまとめ、人数の数字で見せる）。描く数に上限を置いて重くならないようにする

## 5. 仕様上の問題と対応案（実装前の報告）

1. **CrazyGames の審査に通る保証はない。** 遊ぶ量は大きく増えるが、見た目の質でまた落ちる可能性はある → 落ちても GitHub 版と itch.io は良くなるので、無駄にはならない。CrazyGames への提出は1回だけにして、落ちたら終わり（前回と同じ決め方）
2. **進むペースの調整が難しい。** 速すぎると数分で終わり、遅すぎると作業になる → ボットで回数を測り、本人のテストプレイで1回だけ直す
3. **v1 は「完成後に作り込みを続けない」で閉じている。** 今回は本人が新しい目的（CrazyGames）で v2 を決めたので、別の制作として扱い、新しい完成条件を置く
4. **作業量は v1 の数倍。** Phase を4つに分け、各 Phase の終わりで止まっても遊べる状態にしておく
5. **スマホ縦画面の遊びやすさを落とさない。** 横画面に対応しても、縦の画面配置は v1 のままにする

## 6. 完成条件

共通（起動・基本操作・主なルール・クリアまで進める・致命的なバグなし）に加えて：
- タイトルから宇宙大会のエンディングまで、通しで遊べる
- 毎秒 6 回くらいで跳べる人が、**20〜30分** で宇宙大会に勝てる（ボットで確認）
- 強化を買うと、効果が1回目から分かる（数字か見た目が変わる）
- 進み具合が保存され、閉じて開き直しても続きから遊べる
- スマホ縦画面とパソコン横画面の両方で、遊ぶ場所が崩れない
- 日本語と英語の両方で、全部の画面が読める（英語版に外部リンクなし）

## 7. 実装計画

- **Phase 1：大会のくり返し**　大会の一覧・ライバルの記録・勝ったら次が開く・記録用紙にライバルとの比較・保存。見た目は v1 の体育館のまま
- **Phase 2：購買部と強化**　引換券・6つの品物・分身の上限の解放・大きな数字の表示・ボットで進むペースを調整 → **ここで本人のテストプレイ（大会と強化がくり返し遊べる）**
- **Phase 3：会場とエンディング**　会場9つの見た目・記録係とライバルの一言・宇宙大会のエンディング・効果音の追加
- **Phase 4：横画面と英語と仕上げ**　横長の体育館・日英の切り替え・`build.sh portal`・タイトル画面の手直し → **本人のテストプレイ（通しで遊べる）**
